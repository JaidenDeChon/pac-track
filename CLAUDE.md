# pac-track

Read `docs/PLAN.md` before starting work. It holds the roadmap, decisions, data sources and open items.

## Rules

- **Neutral copy.** All user-facing text uses numbers, dates, sources and stance verbs (supports, opposes, contributed, spent). No adjectives, no loaded or editorial language.
- **Tags are positions with evidence**, never labels. Every tag carries an evidence URL and an archived copy.
- **Never sum** direct contributions, outside spending and conduit earmarks into one figure.
- **Every displayed number** carries its data date and source filing ID.
- **FEC donor data** must never be used for solicitation or commercial purposes, including email digests.
- Reading requires no sign-in.
- UI uses Nuxt UI + Tailwind CSS and follows `docs/design/DESIGN.md` and `docs/design/tokens.css`. Design changes are the maintainer's call.
- When a decision in `docs/PLAN.md` changes, update the file in the same change.
